## Regla

Las tareas nuevas se agregan a `03_PLAN_DE_TRABAJO.md`. Los cambios de estado se
reflejan en `ESTADO_PROYECTO.md`. Los documentos históricos no se actualizan
para representar trabajo nuevo.
